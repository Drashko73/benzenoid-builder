# Contributing

Thanks for your interest. Issues and pull requests are welcome.

## Setup

```bash
npm install
npm run dev
```

Before opening a pull request run the same checks as CI:

```bash
npm run typecheck && npm run lint && npm run format:check && npm test && npm run build
```

## Where things live

- `src/core` — the chemistry engine (no DOM). New geometry, validation or format logic
  belongs here, with a unit test in `tests/`.
- `src/ui` — the React app.
- `tests/fixtures` — `.xyz` files generated by the Python generator of the
  [current-density](https://github.com/imilos/current-density) project. Do not edit them by
  hand; regenerate with `scripts/gen-fixtures.py`.

`CLAUDE.md` lists the geometry and file-format conventions that must not change, because
the exported files feed a downstream prediction pipeline.

## Reporting a wrong structure

If the builder accepts a selection that is not a valid planar benzenoid, or rejects one
that is, please open an issue with the share link (the URL of the page contains the
selection) and the expected behaviour.
