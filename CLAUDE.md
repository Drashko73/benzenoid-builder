# CLAUDE.md

Guidance for Claude Code (and humans) working in this repository.

## What this is

A static web app (React + TypeScript + Vite) for drawing **benzenoid molecules** on a
honeycomb grid and exporting them as `.xyz` files. It is a companion to the
[current-density](https://github.com/imilos/current-density) project (ML prediction of
induced current density in C/H molecules) and must stay **byte-compatible with that
project's Python generator** (`src/molgen` there). See README.md for the user-facing
description.

## Commands

```bash
npm run dev          # Vite dev server on http://localhost:5173 (also .claude/launch.json "dev")
npm test             # Vitest: core unit tests + fixtures cross-check + UI smoke tests
npm run typecheck    # tsc -b
npm run lint         # ESLint
npm run format       # Prettier (write)
npm run build        # production build -> dist/
node scripts/screenshots.mjs                      # README screenshots (needs dev server + local Chrome/Edge)
MOLGEN_SRC=../current-density/src python scripts/gen-fixtures.py   # regenerate tests/fixtures
```

Run `npm run typecheck && npm run lint && npm test` before committing.

## Layout

```
src/core/       Pure TypeScript, NO DOM. The chemistry engine.
  types.ts        Cell, Site, Atom, Bond, Molecule, BuildParams, ValidationIssue, ...
  elements.ts     element registry (symbol, Z, colour, bond length to C), formula formatting
  lattice.ts      integer honeycomb lattice -> Cartesian; buildMolecule(cells, params)
  orient.ts       centroid + principal-axis orientation (port of _principal_rotation)
  validate.ts     connectivity, enclosed rings, H-H clashes, MAX_ATOMS sanity cap (1000)
  shapes.ts       families: acene, zigzag, hexFlake, rectFlake
  presets.ts      named molecules (generated from molgen/presets.json)
  xyz.ts          .xyz writer/parser, cells JSON codec
  urlState.ts     share-link (URL hash) codec
src/ui/         React application.
  state/useBuilder.ts   reducer: cells (Set of "q,r" keys), params, view, undo/redo, URL sync
  canvas/               HoneycombCanvas (SVG, pan/zoom, paint), MoleculeLayer (ball-and-stick)
  preview/              ExportPreview: the molecule in the export frame with axes/scale bar
  sidebar/              Summary, Validation, Presets, Parameters, Export panels
  download.ts           file download, clipboard, SVG->PNG
tests/          Vitest. tests/fixtures/*.xyz are GENERATED by the Python molgen (see manifest.json).
scripts/        gen-fixtures.py, screenshots.mjs
```

## Conventions that must not drift

These come from the current-density dataset and its Python generator. Changing any of
them silently breaks the downstream prediction pipeline; `tests/fixtures.test.ts` guards
them.

- **Lattice**: axial cell `(q, r)`, centre `(√3·d·(q + r/2), 1.5·d·r)`, pointy-top. Carbon
  sites are integers `X = 2q + r + a_k`, `Y = 3r + b_k` with corners
  `(0,2) (-1,1) (-1,-1) (0,-2) (1,-1) (1,1)`; Cartesian `(√3·d·X/2, d·Y/2)`. Neighbour
  offsets are keyed by `Y mod 3` (use `((y % 3) + 3) % 3` in JS).
- **Hydrogens**: a carbon with exactly two carbon neighbours gets one H along the missing
  lattice direction, at `chBond`. Two carbons that are lattice neighbours are always bonded
  (even if no selected cell contains that edge) — that is why `validate.ts` reports
  "enclosed rings" instead of the lattice code guessing.
- **Defaults**: `CC_BOND = 1.42`, `CH_BOND = 1.09` Å (fitted to the DFT data; 1.42 beats 1.40).
- **Frame**: all-atom centroid at the origin, z = 0. `orient: 'principal'` puts the long
  axis along +x with the heavier end (third moment) to +x; skipped when the two principal
  moments are within ratio 0.98 (round molecules). For molecules with zero skew the
  eigenvector sign is chosen deterministically (x ≥ 0); numpy may differ by 180°, which the
  fixture test tolerates.
- **Atom order**: carbons sorted by site (X, then Y), then hydrogens in parent order.
- **`.xyz` format**: `%6d` count, two-space blank comment line, rows
  `%6d%22.6f%12.6f%12.6f` with **atomic numbers**, LF, trailing newline. `formatFixed`
  keeps Python's `-0.000000`. Element symbols are an opt-in (`symbols: true`), never the default.
- **Size**: `MAX_ATOMS = 1000` in `validate.ts` is a sanity cap for the editor (largest
  synthesised benzenoid: 264 atoms), not a pipeline constraint. The prediction model's own
  limits (144 training max, 150 padding) belong to that pipeline; do not reintroduce them.
- **Cells JSON** `{"cells": [[q,r],...]}` is the molgen API's input format — keep it stable.

## Working rules

- Keep `src/core` free of DOM and React imports; it is meant to be reusable in Node.
- New chemistry logic goes into `src/core` with a unit test; UI components stay thin.
- Do not edit `tests/fixtures/*` by hand — regenerate with `scripts/gen-fixtures.py`.
- `src/core/presets.ts` mirrors `molgen/presets.json`; if that file changes upstream,
  regenerate the table rather than editing entries.
- Validation issues carry `cells`/`atoms` to highlight and an optional `fix`; the UI
  renders them generically, so adding a check means adding an entry in `validateCells`.
- The share link is the URL hash (`urlState.ts`, row-range encoding `r:q1..q2,q3`); every new
  persistent parameter should be added there with a default-omitting encoding. The hash is
  never written when it would exceed `MAX_SHARE_HASH_LENGTH` (8000) — browsers and mail
  clients truncate long URLs — and the legacy `q,r;q,r` form must keep decoding.
- Element extensibility: `elements.ts` + `BuildParams.terminal` (site key -> element) are
  the extension point for substituents. The writer and the renderer already handle any
  registered element; only the UI is missing.
- Style: Prettier (single quotes, width 100), ESLint recommended + react-hooks. Comments
  explain *why*; the code explains *what*.
- Verify UI changes in the browser (`preview_start` with the `dev` configuration) —
  jsdom has no layout, so the smoke tests cannot see rendering problems.
